# HabaCoin Global: The Universal Kinetic & Multi-Fiat Ledger

HabaCoin is a decentralized, high-performance web platform and Progressive Web App (PWA) that seamlessly bridges human physical movement with global financial rails. 

By utilizing our proprietary client-side **Sustainable Proof of Work (sPoW)** mining engine, users convert their daily physical steps into **Ubuntu Token ($UBUNTU)** assets on the Polygon Blockchain. 

## 🌌 Core Pillars & Ecosystem Architecture
* **Kinetic Mining (sPoW Engine):** Anti-spoofing velocity validators convert raw physical step metrics smoothly into $UBUNTU tokens without destroying mobile battery lifespan.
* **Global Multi-Fiat Settlement Matrix:** Real-time on-chain pricing hooks that stabilize international transactions across over a dozen regional fiat corridors, including East Africa (KES, ETB), West Africa (NGN), North America (USD, CAD), Europe (EUR), Asia (INR, JPY), Latin America (MXN), Oceania (AUD), and the Middle East (AED, SAR).
* **The Ghost Chat Interface:** End-to-end encrypted, zero-trace community rooms powered by secure client-side Argon2id key derivation and automated community token distribution mechanisms ("Chat Rain").

## 🛠️ Repository Architecture & Workspace Tree
* `/backend` - Scalable Express engine controlling global transaction locks and local database persistence layers.
* `/contracts` - Hardhat-optimized Solidity smart contracts defining $UBUNTU tokenomics on Layer-2 network architectures.
* `/miner-client` - Ultra-lightweight, hardware-level Rust core compiled directly to WebAssembly for native multi-threaded browser mining.
* `/src` - The high-fidelity Progressive Web App dashboard interface built with React, Vite, and Tailwind/CSS styling layouts.

## 🔒 Security Alignment
All transactional parameters utilize strict multi-layer security patterns adhering to OWASP Application Security verification criteria. Mobile deployments operate inside isolated Termux/FreeBSD hardware containment paradigms.
